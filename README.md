# subnetting_questions

These questions were taken from "https://subnettingquestions.com/" which doesn't work anymore from what I've seen (message me for credit or removal)

To use it, simply run offline.py, with the database file inside the same directory (or adjust the path to the database)

The program will prompt you for the answer - mostly it will fail detecting if your prompt is correct or not, since it checks if it matches the answer field.
